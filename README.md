# 4onacouch (Couch Game)

Local LAN web version of Four on a Couch with:

- 2 equal teams (minimum 8 players)
- Secret assigned names (fixed after game start)
- Circular seat model with one empty seat
- Random 4-seat couch target block
- Global nickname cooldowns (3 turns)
- Host helper QR page on `localhost:3001`

## Run locally

```bash
npm start
```

Open game on host:

`http://localhost:3000`

Open helper/QR page on host:

`http://localhost:3001`

Join from phones on same Wi-Fi:

`http://<host-lan-ip>:3000`
